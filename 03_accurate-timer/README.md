# 第3回 ずれないタイマーにする

「1秒ごとに1減らす」方式をやめて、「終了予定時刻と今の時刻の差」から残り時間を計算する方式に変えます。`Date.now()` と `useRef` を使います。

## 実行方法

```bash
cd 03_accurate-timer
npm install
npm run dev
```

## 第2回からの変更点

| ファイル | 変更 |
| --- | --- |
| `src/App.jsx` | 残り時間をミリ秒（`remainingMs`）で持つ。終了予定時刻を `useRef` に入れ、`Date.now()` との差から残り時間を求める |

ほかのファイルは、第2回から変更していません。
